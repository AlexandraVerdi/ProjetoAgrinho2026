# ProjetoAgrinho2026

Este site foi desenvolvido como parte do Projeto Agrinho, com o objetivo de apresentar a importância do agro no sudoeste do Paraná, destacando a agricultura, a sustentabilidade, a preservação ambiental e as tecnologias utilizadas no campo de forma criativa e interativa.

O projeto também serve como prática de programação web utilizando HTML, CSS e JavaScript.

# Objetivos do Projeto

- Valorizar o agro no sudoeste do Paraná
- Incentivar a consciência ambiental
- Mostrar a importância da sustentabilidade
- Desenvolver criatividade e programação
- Trabalhar pesquisa e inovação no campo
